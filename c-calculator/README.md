# C Calculator

My first C programming project.

## About

A simple command-line calculator written in C. The program allows the user to perform basic arithmetic operations on two numbers.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Invalid operator handling

## What I Learned

This project helped me practice:

- Variables
- `double` and `char`
- `printf()`
- `scanf()`
- Arithmetic operators
- `if`, `else if`, and `else`
- Logical operators
- Basic input handling

## How to Compile

```bash
gcc calculator.c -o calculator
```

## How to Run

```bash
./calculator
```

## Example

```text
x : 10
choose your operator('+','-','*','/') : *
y : 5
result : 50.00
```
