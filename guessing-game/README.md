\# Number Guessing Game 🎯



A simple number guessing game written in C.



\## How It Works



The player has \*\*3 attempts\*\* to guess the secret number.



\* Guess correctly → \*\*You win!\*\*

\* Use all 3 attempts → \*\*You lose!\*\*



\## Technologies



\* C

\* GCC

\* Git

\* GitHub



\## How to Run



Compile:



```bash

gcc main.c -o guessing\_game

```



Run on Windows:



```bash

guessing\_game.exe

```



Run on Linux/macOS:



```bash

./guessing\_game

```
